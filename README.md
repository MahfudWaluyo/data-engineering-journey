# 6-Week Journey to Become a Junior Data Engineer

Repo ini adalah dokumentasi perjalanan pribadi saya untuk mempelajari bidang **Data Engineering** secara terstruktur dalam waktu 6 minggu. Tujuannya adalah membangun fondasi yang kuat, memahami tools yang digunakan di industri, dan akhirnya mengerjakan proyek akhir berupa **data pipeline produksi**.

---

## 📗 What You Will Learn (Weekly Breakdown)

### **Minggu 1 — Foundation & Python for Data Engineering**
Fokus pada dasar Python, struktur data, module, serta konsep fundamental data engineering.

### **Minggu 2 — Data Pipeline & ETL Concepts**
Belajar konsep ETL/ELT, desain arsitektur pipeline, workflow orchestration, dan dasar Apache Airflow.

### **Minggu 3 — Data Warehousing & Cloud Basics**
Mempelajari data warehousing (OLAP, star schema) serta pengenalan cloud infrastructure.

### **Minggu 4 — Modern Data Stack & Streaming**
Eksplorasi tools modern seperti dbt, streaming basics, serta arsitektur data real-time.

### **Minggu 5-6 — Capstone Project**
Membangun *production-ready* data pipeline end-to-end sebagai proyek akhir.
